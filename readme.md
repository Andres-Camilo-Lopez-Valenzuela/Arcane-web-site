# 🌌 Arcane Fandom Web — Proyecto de Fanpage Responsiva

## 🧠 Descripción

**Arcane Fandom** es una página web estática creada como homenaje a la serie animada *Arcane*, del universo de *League of Legends*. El sitio incluye una sinopsis introductoria, navegación estilizada, música de fondo mediante una playlist de Spotify y un diseño visual inmersivo, pensado para ofrecer una experiencia de usuario atractiva.

Este proyecto forma parte de mi portafolio personal como desarrollador frontend y demuestra mis habilidades en diseño responsivo, optimización de carga y maquetación con HTML y CSS.

---

## 🔧 Tecnologías utilizadas

- HTML5
- CSS3 (incluyendo `position`, `z-index`, `media queries`, y `background techniques`)
- Fuentes personalizadas de Google Fonts
- Spotify Embed API
- Optimización de carga con `preload`, `lazy loading` y jerarquía visual

---

## 📱 Características destacadas

- 🎨 Fondo dinámico con imagen de alta calidad (`background-image` + `cover`)
- 📌 Encabezado fijo con logo e ítems de navegación interactivos
- ✨ Animaciones de hover para enlaces con transición fluida
- 📖 Bloque de sinopsis con gradiente para facilitar la lectura
- 🎧 Playlist de Spotify integrada directamente en la página
- 🌐 Diseño adaptable para distintas resoluciones con posibilidad de `media queries`
- 💡 Preparado para agregar efectos AOS (Animate On Scroll)
